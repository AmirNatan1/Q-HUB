# 1. WHY THIS REDIRECT EXISTS

Phases 1–3 produced a technically strong and visually distinctive foundation, but human review identified a site-level strategic drift.

The existing homepage increasingly makes one approved POC — Maradin × Hyundai CRADLE TLV — carry too much of the website narrative:

- APERTURE uses its footage;
- NEED becomes its need;
- FIND resolves toward it;
- TEST explains its test;
- PROVE becomes its evidence;
- the homepage then directly opens its Field Record;
- `/proof` currently contains that same record as its only public item.

The result risks making the website feel as though **Quantum Hub exists to frame one POC**.

That is the wrong hierarchy.

The human owner has explicitly corrected the north star:

> **QUANTUM IS THE PROTAGONIST.**

The website’s first purpose is to project Quantum’s presence and activity into the world.

Its second major purpose is to make strong startups want to work with Quantum.

One of the strongest reasons a startup should want to work with Quantum is the industrial ecosystem around it — especially its approved founding and strategic partners.

Individual POCs are evidence.

They do not define the brand.

# 12. REAL-WORLD PERFORMANCE — THIS IS A CREATIVE GATE

The human owner experienced the deployed Cloudflare preview as severely laggy, to the point of near unusability.

Local Lighthouse 100 does not override that human observation.

Treat this as a real defect.

## 12.1 Performance work begins BEFORE new spectacle

Before implementing the full redirect:

1. capture a baseline against the Phase 3 starting homepage;
2. use the production build, not dev server;
3. run a deterministic full homepage journey;
4. collect frame-timing and runtime evidence;
5. inspect WebGL/media lifecycle.

Create:

`docs/PHASE_R_RUNTIME_DIAGNOSTIC.md`

and machine-readable artifacts under:

`artifacts/performance/phase-r/`

## 12.2 Required baseline/candidate metrics

At minimum capture:

- requestAnimationFrame frame deltas during deterministic scroll;
- p50 / p95 / p99 frame interval;
- count of frames > 33.3ms;
- count of frames > 50ms;
- longest frame interval;
- long tasks where available;
- total runtime JS errors;
- total console errors attributable to Q-HUB;
- WebGL canvas active/inactive state by act;
- whether offscreen video continues playback;
- rendered device pixel ratio / effective canvas backing resolution;
- memory signal where browser APIs expose it;
- journey duration and viewport.

Use:
- 1440×900 desktop;
- 390×844 mobile emulation;
- production build;
- deterministic browser version recorded in the artifact.

A local synthetic run does not represent every physical device, so disclose that honestly.

## 12.3 Runtime lifecycle requirements

At final candidate:

- no continuous WebGL rendering when the relevant visual state is not active;
- no continuous WebGL rendering when document is hidden;
- no unnecessary video decode offscreen;
- no background media playback merely to preserve a poster state;
- pointer updates must be coalesced to animation frames;
- do not trigger synchronous layout repeatedly inside pointer/scroll loops;
- avoid full-viewport paint-heavy filters;
- cap DPR conservatively;
- mobile must not pay for desktop-only shader detail;
- reduced motion must not run decorative loops;
- teardown listeners/observers cleanly.

## 12.4 Adaptive quality

If profiling shows ordinary hardware can miss frame budget, implement a small dependency-free quality strategy.

Acceptable tools include:
- lower DPR;
- lower shader update rate;
- one-shot rendering when state settles;
- static DOM/SVG substitution;
- disabling nonessential parallax;
- pausing video;
- lowering media resolution;
- simplifying masks.

Do not use vague user-agent detection.

Prefer capability/performance based behavior.

## 12.5 Hard human performance gate

The final Human Review Package must state:

> **Synthetic performance PASS does not constitute final runtime acceptance. Human testing of the branch Cloudflare preview on ordinary hardware remains required.**

No production release can be accepted if the human owner still experiences severe jank.
